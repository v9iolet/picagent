# 套图主图背景与上架文案交付调整

2026-11-22 联调后，工作台统一了国内与国际站的主图背景规则，并确定由套图批次交付上架文案。本决策更新 ADR 0006 中的白底精修和主图背景配置，以及 ADR 0007 中的文案入口和超限校验。 [ADR 0006](0006-suite-one-click-studio.md)、[ADR 0007](0007-listing-copy.md)

## 决策

- **按站点范围生成主图。** 10 个国际平台使用纯白背景（RGB 255,255,255），主图禁止添加文字、Logo、水印、边框和装饰。6 个国内平台按商品和平台场景策略生成，允许灵活背景。国际站在 `main` 类别按配置生成 N 张白底主图，详情图以实拍原图作为外观参考。新流水线从结构规划开始，配置只显示站点背景提示。画布仍可按需精修单图，历史精修暂停批次仍可恢复。
- **上架文案随套图直出或事后生成。** 用户可以开启配置里的文案开关，在结构计划确认后并行生成，也可以打开结果批次的文案抽屉，基于同批次实拍原图和已确认卖点按需生成。创作功能栏去除独立文案入口，已有文案任务和版本继续经由文案 API 保存和读取。图片与文案各自记录生成状态。
- **按 16 个平台配置差异化字段并提供软警告。** 平台规则定义标题、卖点和专属字段。Amazon 支持商品亮点和后台搜索词，Etsy 支持商品标签，Shopify 支持 SEO 标题和描述，适用的国内平台支持副标题或话题标签。无效 JSON 结构、字段类型及命中禁用词仍硬拦截。字符数、UTF-8 字节数与条数超限时保留结果，按平台上限提示用户修改，用户可以编辑并保存为新版本。

## 影响

- 结构规划校验已发布模板能否表达平台背景、市场、比例及自定义分组。模板版本落后时，批次提示在模板库发布新版结构计划模板。失败结果保留相应阶段返回的错误码和说明。
- 迁移 028 更新平台档案的主图背景和国际站策略。历史 `white_preferred` 仍为数据库允许的取值。
- 上架文案的入口、批次抽屉、差异化字段及软警告在票 17 落地。旧文案版本仍可查看和复制。
