# 爆品图反推重构为爆品图复刻

爆品图反推只输出提示词，用户需要再进画布绑定白底图才能出图。参考美图设计室「爆款图复刻」，改为「参考图 + 产品图 → 一键复刻出图」，提示词保留为可见、可编辑、可冻结的中间产物。本决策修改 CONTEXT.md 中「爆品图反推不直接生成商品图」的定义，并修订 [ADR 0006](0006-suite-one-click-studio.md) 中功能栏、方案来源和画布列表的相关条目。

## 决策

- 功能栏「爆品图反推」改为「爆品图复刻」，路由 `/create/replica`，采用 ADR 0006 三栏骨架。旧 `/reverse` 跳转新路由，旧方案只读保留。
- 一期参考图 1–6 张、仅本地上传；产品原图 0–6 张，可上传或从资源库选择已发布白底图/原图。每张参考图产出 1 张图。导入链接与采集插件不做。
- 复刻程度为单选二档：参考风格 `compose`、高度复刻 `high`（默认），对应两套 `replica_prompt` 模板。复刻类型（电商商品图、服饰电商图、营销海报、社媒图文、其他）作为模板变量和默认比例依据，不拆分独立管线。
- 两段式生成：一次视觉模型调用对整组参考图分析，输出 `replica-prompt-v1`（任务名、共享风格、每张图的视觉结构、新文案与最终提示词）；再按卡复用现有生图执行层。生图输入为产品图 1..k 加参考图，provider 不传角色，图片角色必须写进最终提示词。
- 文案事实边界：新文案中的参数、数字、功效、规格只能来自本批次「商品信息」（人工补充商品事实）或产品图可见内容；参考图中的品牌、Logo、参数、促销与认证一律不迁移；真人模特替换为 AI 模特。无产品图时结果标记为「风格示意」。
- 数据复用方案表：新增 `origin = "replica"` 与任务卡 `originKind = "replica"`，流水线记录增加 `replica_analyzing` 阶段。复刻批次不进入画布列表，也不提供带入画布；画布统一接管各创作功能的内容另行决策。
- 新增通用「生成记录」：结果区头部「新建」旁的右侧抽屉，按 `origin` 列出历史批次，支持关键词与分页；结果区只显示当前批次。商品套图同步改造，取代 ADR 0006 中「结果区承载历史批次」的形态。

## Considered Options

- 保留只出提示词：用户仍需多步手工到画布出图，不解决核心诉求。
- 两种复刻程度可同时勾选：结果数与提示词快照难以解释；竞品源码实际也是单选。
- 生成前强制填写卖点文案：成本高；改为选填「商品信息」作为唯一事实来源，出图后用图片编辑器改字纠错。
- 另建 `replica_*` 表：需要重复实现批次状态、任务卡、重试与导出；复用方案表成本更低。

## Consequences

- 迁移需扩展 `suites.origin`、`suite_tasks.origin_kind` 与 `suite_pipeline_runs.phase` 的 CHECK；画布列表、套图 feed、来源文案按新取值调整。
- 生图输入注入从 `reverse_import` 专用逻辑泛化为按任务记录的参考图 objectKey 注入。
- 套图结果区不再纵向堆叠历史批次，历史经「生成记录」抽屉访问。
- 旧反推写接口不再接受新建，旧数据、资产与已导入画布的任务卡保持可读。
