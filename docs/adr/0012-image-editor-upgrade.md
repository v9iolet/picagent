# 图片编辑器按单一工具提交并附带商品原图

结果区与画布共用的图片编辑器效果不理想。源码调研发现：只发来源图，不附带商品原图；蒙版编码与 OpenAI 系 edits 接口的透明通道语义不一致；单独使用「重新编辑」时整段原提示词被原样发出；扩图没有扩展画布；多个操作合并成一次请求，互相干扰。参考美图设计室的 AI 改图、编辑文字、商品还原，在原有编辑窗口内调整。本决策修订 [ADR 0003](0003-image-editor-tool-and-lineage.md) 中「编辑会话允许组合多个有顺序的操作」「扩图支持原比例」两条，并补充其「禁止静默拼接成普通 prompt」条目的降级方式。

## 决策

- 一次提交只执行一种工具。编辑文字和添加文字一次可以处理多条，蒙版类工具一次只允许一个蒙版，AI 改图、再次生成、商品还原、扩图都单独提交。多步修改在子卡上继续进行。
- 「重新编辑」改为 AI 改图：输入为空时等同于再次生成；有输入时只执行该指令，并附保持约束，不再以原提示词作为修改指令。
- 新增商品还原工具。外观依据默认取版本快照中 `role=product` 的批次原图，可以指定其中一张或另外上传。
- AI 改图、局部重绘、扩图、商品还原、再次生成附带商品原图，并在提示词中声明各张图的角色。文字类操作和消除不附带商品原图。
- 蒙版编码以对当前渠道的实测结论为准。如果不生效，局部重绘和消除改用区域描述，并在界面上提示，快照记录 `maskApplied=false`，属于显式降级而非静默拼接。
- 扩图先在服务端按目标比例扩展画布，取消「原比例」选项。

## Considered Options

- 保持组合提交：蒙版会作用于整个请求，文字操作被限制在蒙版内，多个指令之间还会互相干扰；美图也是每种编辑单独请求。
- 商品还原必须上传参考图（美图做法）：我们的版本快照里已经保存了批次原图，默认使用它，可以少一步操作。
- 所有操作都附带商品原图：文字类修改时，模型可能顺带重绘商品。

## Consequences

- 编辑快照增加单一工具、附加输入图、蒙版是否生效三类信息；子卡再次生成按快照完整重放。
- 用户做多步修改需要在子卡上连续编辑，子卡数量会增加。
- 编辑请求的质量跟随模型设置，单张费用可能上升。
