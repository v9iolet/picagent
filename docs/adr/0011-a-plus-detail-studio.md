# 新增 A+详情创作功能

ADR 0010 只为 A+ 详情预留了商品卡字段。现在参考美图设计室「A+详情」，把它做成创作功能栏的第四个功能：用户上传商品原图并填写卖点，按所选 A+ 模块逐张出图，Amazon 按 A+ 像素规格交付，其他平台按通用比例输出分模块详情图。本决策修订 ADR 0010 中「A+ 详情本期仅做商品卡字段预留」，以及 CONTEXT.md 中功能栏只有三项的共识；尺寸处理补充 ADR 0006「比例由模型能力配置决定」。

## 决策

- 定位为「A+/详情页」，所有平台可用。平台表新增详情尺寸预设：Amazon 提供高级 A+（Web 1464:600、移动 600:450）、普通 A+（970:600）和通用比例，其他平台只提供 1:1/3:4/9:16/16:9。整批统一一个尺寸，高级 A+ 两端可同时勾选，每端各自生成。
- 模型输出不保证像素精确。A+ 预设先按近似比例生成，再由服务端裁切缩放到交付尺寸，生成尺寸与交付尺寸都写入快照。1464:600 强制 1K，因为 2K 会超出长边上限。
- 两段式且需要人工确认：先用视觉模型规划，输出整体策划思路和每个模块的文案要求、画面要求；用户在方案确认阶段可改文案、排序、删除模块，确认后才出图。规划时冻结输入快照，输入变化即判定方案失效。这与套图的自动确认不同，原因是 A+ 文案逐张定制，生成前修改的成本远低于事后重绘。
- 提示词拆分为规划总模板、16 份模块规则模板（只拼入所选模块）和图像包装指令模板，每份模板可单独调优、单独发布。
- 数据复用方案表：`origin = "aplus"`，任务卡 `originKind = "aplus"`，流水线新增 `aplus_planning`、`awaiting_confirmation` 阶段。A+ 批次不进入画布。
- 结果页本期包含商品还原（指定原图重绘）、AI 改字（OCR 识别文字与 bbox 后，按指令整图重绘，不依赖蒙版）和详情长图（服务端拼接）。

## Considered Options

- 只做 Amazon：可复用的平台配置和国内用户都会被排除在外；竞品同样不限平台。
- 高级 A+ 首尺寸生成、其余尺寸扩图（竞品做法）：从 2.44:1 改到 4:3 需要补出大量画面，横幅排版放不进移动端，现有扩图也不支持这两个比例。
- 沿用套图的自动确认：文案错误只能逐张重绘，成本更高。
- 原样交付、不裁切：不满足 Amazon 的像素要求。
- 独立建表：要重复实现批次状态、任务卡、重试与导出。

## Consequences

- 迁移扩展 origin、origin_kind、phase、prompt stage 的 CHECK，平台表增加详情尺寸预设列。
- 任务卡增加交付图，下载、ZIP、长图使用交付图，原始生成图保留。
- 图片编辑器的扩图比例不覆盖 A+ 比例；在 A+ 卡上编辑后，交付裁切需要重新执行。
